# Referee Cut – Downloads

Öffentliche Downloadseite und Installationspakete. Dieses Repository enthält keinen Anwendungsquellcode.

Website: https://sebaw13.github.io/referee-cut-downloads/

## Aktueller Stand

- macOS 0.3.0: Testversion für Apple Silicon, macOS 26+.
- Ad-hoc signiert, nicht notarisiert; automatische Updates sind deaktiviert.
- Windows 0.3.0: x64-Installer und portables ZIP; auf Windows-Runner einschließlich Installation, Wiedergabe, Export und Deinstallation geprüft.
- Windows-Pakete sind ohne Herausgeberzertifikat; automatische Updates sind deaktiviert.

Die Website wird über GitHub Pages aus dem Hauptverzeichnis von main veröffentlicht.
Installationsdateien und SHA256-Prüfsummen stehen unter Releases.
